The settings file I ended up with to make as much of the Avaya 9650 work with FreePBX/Asterisk.

This phone doesn't really like working outside of an Avaya envrionment, but it can still be useful!

You'll need to flash the latest SIP firmware. 2.6.17 from 2017 seems to be the last release on the Avaya site for this model.

Contacts

The 8 function buttons

Speed dial
